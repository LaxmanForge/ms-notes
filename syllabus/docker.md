## **Text Books**

1. **Docker Deep Dive** – Nigel Poulton  
    Covers Docker fundamentals, architecture, and practical usage in a simple manner.
2. **Docker in Action** – Jeff Nickoloff and Stephen Kuenzli  
    Focuses on real-world Docker applications, container management, and deployment.
3. **Using Docker** – Adrian Mouat  
    Explains Docker concepts along with best practices and security aspects.

##  **Reference Books**

4. **The Docker Book: Containerization is the New Virtualization** – James Turnbull  
    Provides detailed understanding of Docker internals and containerization concepts.
5. **Kubernetes Up & Running** – Kelsey Hightower, Brendan Burns, Joe Beda  
    Useful for understanding orchestration and integration with Docker.
6. **Docker for Developers** – Richard Bullington-McGuire  
    Focuses on development workflows and Docker-based application deployment.
